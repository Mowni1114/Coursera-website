# 🎓 Coursera Website Clone

A responsive **Coursera-style learning platform** developed using modern web technologies.  
This project allows users to browse courses, view learning content, and manage academic information through a structured interface.

---

## 🚀 Project Overview

The **Coursera Website** is designed to simulate an online learning platform where students can explore courses, access educational resources, and interact with academic modules.

This project focuses on:
- Clean UI design
- Structured module system
- Academic & Non-Academic management
- User-friendly experience

---

## ✨ Features

✅ Course Listing Page  
✅ Responsive User Interface  
✅ Academic Module Management  
✅ Non-Academic Module Management  
✅ Student Information Handling  
✅ Placement Management Module  
✅ Modern Layout & Navigation  
✅ Scalable Project Structure

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository
```bash
git clone https://github.com/Mowni1114/Coursera-website.git
cd Coursera-website
2️⃣ Backend Setup (Django)
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
3️⃣ Frontend Setup (React)
cd frontend
npm install
npm start
